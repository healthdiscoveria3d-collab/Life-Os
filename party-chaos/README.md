# PARTY CHAOS 🎉

A fast, funny browser party game for 2–6 friends or bots. No accounts, no downloads, no Roblox-style world.

## Modes
- Friends + bots
- Tap Frenzy
- Higher or Lower
- Don't Blink
- Pick a Disaster
- Chaos events
- Normal / Wild / Nuclear chaos

Designed as a static web game and playable on phones and desktop browsers.
